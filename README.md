# alice-neko

Алиса AI в браузере, запущенном на сервере. Откройте `http://<сервер>/alice/` — увидите
интерфейс Алисы, а весь трафик к сайту идёт с IP сервера. Под капотом
[neko](https://github.com/m1k1o/neko): Chromium в Docker, картинка передаётся по WebRTC.

Что настроено:
- Chromium в kiosk-режиме сразу открывает `START_URL` (по умолчанию alice.yandex.ru), профиль (вход в аккаунт) хранится в volume;
- страница без панелей neko (`?embed=1`), только видео;
- разрешение виртуального экрана подстраивается под окно пользователя (сервис `autofit`).

## Установка Docker

Linux-сервер (Ubuntu, Debian и др.) — официальный скрипт Docker, ставит Docker Engine вместе с плагином Compose:

```sh
curl -fsSL https://get.docker.com | sudo sh
docker compose version   # проверка
```

Windows и macOS: установите [Docker Desktop](https://docs.docker.com/desktop/), Compose входит в него.

## Настройка

```sh
cp .env.example .env
```

В `.env`:
- `PUBLIC_IP` — внешний IP сервера (локально `127.0.0.1`);
- `USER_PASSWORD`, `ADMIN_PASSWORD` — смените;
- `HTTP_PORT` — порт веб-интерфейса (по умолчанию 80);
- `START_URL` — сайт, который откроется в браузере;
- `WEBRTC_PORT` — порт видеопотока (по умолчанию 52000).

Нужны входящие порты `HTTP_PORT`/tcp (веб-интерфейс) и `WEBRTC_PORT` tcp+udp (видеопоток WebRTC).
На чистом сервере они обычно открыты сразу; если у хостера есть файрвол
(Security Group, Cloud Firewall), разрешите их там.

## Запуск

```sh
docker compose up -d
```

Откройте `http://<сервер>/alice/` (локально `http://localhost/alice/`).

## Вход

Роли две — пользователь и администратор. Роль определяется паролем, а не именем:

| Роль | Пароль | Может |
|---|---|---|
| пользователь | `USER_PASSWORD` из `.env` | смотреть и управлять браузером (клик по экрану) |
| администратор | `ADMIN_PASSWORD` из `.env` | то же + настройки комнаты, кик участников, смена разрешения |

Пароли по умолчанию из `.env.example` — `neko` и `admin`, смените их перед запуском на сервере.
Поле имени — любое отображаемое имя. После входа кликните по экрану, чтобы получить управление.
Админ-панель neko открывается по `/alice/?embed=0`.
